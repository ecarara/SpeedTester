# Suporte

Mantenedor: [Edson Angelo Carara (`ecarara`)](https://github.com/ecarara). O
repositório oficial é <https://github.com/ecarara/SpeedTester>.

## Antes de pedir ajuda

Consulte o [README.md](README.md), [docs/operations.md](docs/operations.md),
[docs/api.md](docs/api.md), [docs/development.md](docs/development.md) e
[SECURITY.md](SECURITY.md).

Não publique tokens, arquivos `.env`, bancos SQLite, endereços públicos ou
logs contendo dados sensíveis.

## O que incluir

Ao abrir uma issue de suporte, informe versão/commit, sistema operacional,
Docker/Compose, runner, configuração relevante sem segredos, `/health`, logs
sanitizados, comportamento esperado/observado e passos de reprodução.

## Canais

Use Issues para bugs reproduzíveis e solicitações de funcionalidade. Para
vulnerabilidades, siga o processo privado de [SECURITY.md](SECURITY.md). Para
dúvidas amplas, use Discussions quando o repositório tiver essa funcionalidade.
